Источники: `source/build_design.py` генерирует токены/содержание; `source/styles.css` - компоновка; `source/app.js` - только сценарный прототип. Изменять исходник, затем генерировать каталог/изображения, не редактировать independently generated HTML/PNG. Не переносить дизайнерское меню, роли из query, localStorage текста, искусственные timestamps и setTimeout-сохранение в продукт.

## Повторный экспорт

Нужны Python, Playwright, Pillow и установленный Chromium/Chrome. `CHROMIUM_PATH` указывает исполняемый браузер; без него ожидается `/usr/bin/chromium`. Для обзорных листов DESIGN_FONT/DESIGN_FONT_BOLD указывают локальные шрифты; в этой редакции использован Arial для подписей обзора и системный web-font внутри UI. Это инструменты экспорта, не зависимости приложения.

```sh
python source/build_design.py
python source/render_design.py
python source/qa_checks.py
python source/extract_ui_copy.py
python source/build_handoff.py
```

Генератор handoff обновляет каталог и реестр; сопровождающие требования поддерживаются в docs/design.md. Проверки находятся в [qa-report](qa/qa-report.md). Контрольные суммы - SHA256SUMS.txt; 27.09 актуализированы вводные Markdown и их строки checksum, изображения/HTML не переэкспортировались. При повторной генерации сохранить предупреждение об историческом статусе. Исходный дизайн-промпт не включён: он не нужен ни для просмотра, ни для реализации. Происхождение - [provenance](provenance.json).

Пакет не содержит production-сессии, backend, настоящих приглашений, доставки MAX или подтверждённого аудита доступности на устройствах. Их задачи и критерии записаны в docs/team и docs/acceptance.md.
