# Проверка проектного пакета

Дата: 22 сентября 2026 года. Проверка относится к локальному HTML-источнику и фактически экспортированным PNG, не к работающему MAX или реальному backend.

## Файлы и геометрия

Проверены 118 основных PNG: существование, уникальный ID/тема, фактические размеры пикселей. Для каждого выполнен браузерный аудит. Элементов за горизонтальными границами viewport: 0. Внутренних горизонтальных переполнений проверенных текстовых блоков: 0. Кнопок с геометрией менее 44×44 px: 0. Ошибок JavaScript при рендеринге: 0.

Длинные страницы имеют 60 дополнительных первых viewport. R01 действительно использует основной текст 36 px, заголовок 54 px и ширину 320 px. R02 содержит внутреннюю вертикальную прокрутку; фиксированный PNG не изображает весь scroll-контент одновременно.

## Контраст

Измерены 32 выбранные пары токенов в обеих темах методом относительной яркости sRGB: (Lmax + 0.05) / (Lmin + 0.05). Все прошли указанный в JSON порог. Минимальное отношение для проверенных текстовых пар — 5.19:1. Для текста задан порог 4.5:1, для проверенных границ контрола/фокуса — 3:1. Даже disabled-текст проверен, хотя это отдельная проектная цель. Список и значения — contrast-report.json. Это проверка выбранных реальных пар, не утверждение о полном соответствии WCAG всех состояний приложения.

## Проверенные переходы

22 из 22 локальных браузерных проверок пройдены. Точные условия — interaction-checks.json и исходник source/qa_checks.py.

- PASS — Открыто отдельное подтверждение D07
- PASS — Дверь явно не затрагивается
- PASS — После связи нет авторских кнопок у диспетчера
- PASS — Ручной путь при недоступности подсказки
- PASS — Все три наблюдения доступны
- PASS — Не могу проверить не превращается в положительный результат
- PASS — Свет и дверь остаются двумя отдельными пунктами
- PASS — Дверь не получила успешный статус
- PASS — Отзыв не превратился в 100 процентов выполнения
- PASS — Сохранение плана не создаёт вымышленного отчёта

## Визуальная проверка и границы

Просмотрены опорные экраны A05/A13/D01/D06/M05, широкий выбор связей R04, узкий крупный текст R01, планшетный контейнер R02, клавиатурный вариант X07 и сравнительные компоненты C03. Проверены кириллица, иерархия, переносы, источник сведений, отдельная дверь и доступность основного действия. Финальные обзорные листы дают дополнительную проверку согласованности каталога.

Не выполнялись испытания реальных клиентов MAX, внешней клавиатуры каждого устройства, screen reader, сетевых конфликтов с настоящим сервером, одноразовых приглашений и разграничения прав на сервере. Отсутствие горизонтального переполнения не заменяет полноценный аудит доступности. Файлы не доказывают подключение API. Контакт поддержки и политика данных требуют реальных значений до выпуска.
