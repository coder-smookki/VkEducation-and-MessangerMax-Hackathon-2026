# Возможное расширение: похожие обращения

Исторические макеты 22.09.2026; сверено с кодом и release-конфигурацией 27.09. S01/S02 - отдельные проектные состояния, не включённая функция опубликованного Mini App. Пакет содержит четыре основных PNG в двух темах и два дополнительных первых viewport S01. Используется только разрешённый контекст; пример собственного предыдущего №112 синтетический. Невыполненный поиск не означает отсутствия совпадений. Объединение, раскрытие соседей и запрет нового обращения не предусмотрены.

В Python существует внутренний `/internal/v1/similar-cases` и производный Chroma-индекс с проверкой версий. Это не пользовательский маршрут: в release Kafka выключена, публикация снимков из продуктовых CRUD/outbox и UI поиска не подключены. Рабочая RULES-подсказка отчёта не использует этот индекс. Перед включением расширения выполнить [контракт04](../../contracts/04-similar-cases.md) и отдельную приёмку; текущая матрица - [screens](../../docs/screens.md).
