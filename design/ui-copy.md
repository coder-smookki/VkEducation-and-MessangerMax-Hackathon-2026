# КОРЕНЬ — точные тексты интерфейса

Исторический снимок текста прототипа 22.09.2026, а не актуальный словарь ДомПульса. Содержимое 62 ID сохранено для сопоставления с теми же PNG; имена, даты, адреса, состояния и поля здесь синтетические. Для реализации использовать `frontend/src/`, [действующий дизайн](../docs/design.md) и [матрицу API](../docs/screens.md). Состояния, отсутствующие в API, нельзя восстанавливать из этих текстов как рабочие функции; проверка выпуска 27.09 - [отдельный протокол](../docs/qa/profile-visual-2026-09-27.md).

Тексты извлечены из отрендеренного DOM каждого ID. Светлая и тёмная темы используют одинаковую редакцию; на C обе колонки сохранены. Подписи внешнего контейнера B/R и подписи листов C — дизайнерские пояснения, не пользовательские элементы Mini App. Ввод/placeholder перечислены отдельно, поскольку не входят в обычный innerText. Динамические сообщения прототипа дополнительно находятся в source/app.js.
