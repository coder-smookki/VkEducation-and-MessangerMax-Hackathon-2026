## Чего пока нет и что блокирует рабочий продукт

Наблюдения автора и история как работающие endpoints; архив и отзыв отдельного пункта; текстовый бот/durable workers/доставка; настоящий UI вместо demo; production-конфигурация и подтверждённый deployment. Вход через MAX проверен независимыми HMAC-векторами и HTTP-тестами, но не на реальном web/mobile MAX: нужен HTTPS-стенд. ownerDisplayName и displayName в /me возвращают null - колонки имени в app_user нет. Отчёт в MVP вводит только диспетчер: сценарий EXECUTOR требует назначения исполнителя, которого нет. Поле analysis в ответе на сохранение отчёта всегда MANUAL_REQUIRED - сравнение текста с пунктами не подключено.
