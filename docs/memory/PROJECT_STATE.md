## Чего пока нет и что блокирует рабочий продукт

G2 с двумя реальными аккаунтами и MAX mobile не пройден. Настоящие bot_started/message_created и ответы отправщика проверены на HTTPS-стенде 27.09; это не delivery receipts для всех уведомлений. Воркеры стенда включены. Вопрос о наблюдении в боте задаётся текстом; раунд хранится на сервере, старый ответ не должен менять новый раунд. Двухролевую проверку отчёта, наблюдения и остатка проводит София отдельно.

Вход в MAX Web проверен с настоящим Bridge и серверной сессией. Для iframe нужны Secure/None у обеих cookies; отдельный CrossSiteCookieHttpTest проверяет флаги и CSRF, а служебный WebAppData hash нормализуется до запуска роутера. ownerDisplayName/displayName по-прежнему null. Отчёт вводит диспетчер; EXECUTOR и назначения не реализованы. На тестовом сервере включён RULES v2, но качество без независимого holdout не принято; живой двухролевой анализ отчёта ещё не засчитан. Разбор свободной фразы на пункты остаётся STUB: автор задаёт список явно. Для нескольких домов бот направляет в приложение.

Публичный smoke HTTPS, SHA, закрытых actuator/demo и портов пройден. Ещё нужны устройства/ручной screen reader, независимый запуск из чистого checkout, серверная нагрузка. HTTP 80 извне попадает в другой обработчик, требуется исправить перенаправление TCP к nginx. Сертификат выпущен вручную DNS-01, автопродления нет. Публичный URL и инструкции - [release](../release.md). Кандидат для сдачи ещё не заморожен.
