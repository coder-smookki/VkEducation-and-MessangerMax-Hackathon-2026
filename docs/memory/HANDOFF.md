## Не потерять при интеграции

receipt, nextAction, displayNumber, отчёты и связи реализованы и возвращаются; TARGET остался только allowedActions и административное решение по пункту.

Сохранение отчёта не создаёт раунд: раунд создаёт только подтверждённая связь, и только у своего пункта. Набор связей применяется целиком или не применяется вовсе. Повтор пары отчёт-пункт закрыт навсегда: новые сведения оформляются новым отчётом, а не новым ключом идемпотентности.

RULES смешивает субъекты в одной фразе; исправить S-06 и добавить независимые перефразировки. Health режима также требует исправления. STUB/manual честный; не выдаватьdevelopment16/16 за гарантию. SimilarCasesService не вызывать внутри SQL-транзакции, события CRUD отправлять только через durable outbox.
