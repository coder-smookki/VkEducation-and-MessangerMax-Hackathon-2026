## Как начать параллельно

Прочитать [parallel-development.md](../parallel-development.md): за первый час сверить C1, затем каждый начинает свой компонент. Кирилл строит K2/K3 на согласованных примерах до готовности S1-S3; Семён тестирует серверные команды на отдельной PostgreSQL до готовности K1; Никита использует текущий C3 без ожидания обоих.

Новый подробный порядок: [Кирилл](../team/kirill.md), [Семён](../team/semyon.md), [Никита](../team/nikita.md). Точки сборки I1/I2/I3 в [общем плане](../plan.md). K5a нужен до проверки S5, а не после G2. Примеры запросов и версии - [worked-example.md](../worked-example.md), проверки - [acceptance.md](../acceptance.md).

Следующие решения T0: фактические часы каждого, актуальный кейс/допуски, бот/домен, доступное железо NLI. Ответственного указывает соответствующая задача; отсутствие внешнего доступа не останавливает локальные контракты. Никакие runtime-сессии, новые DTO и workers из подробного плана ещё не реализованы.
