## Что опубликовано

- «О сервисе» доступно до входа и из профиля: фактические данные, ручной запрос удаления на согласованный `smookki@yandex.ru`, предупреждение про 112. Архив, отзыв и выход не называются удалением. Автоматического удаления и обещанного срока обработки нет.
- Учебный стенд явно маркируется: `TRAINING_MODE=true` передаёт build arg `VITE_TRAINING_MODE`; Java получает `CASE_NUMBER_PREFIX=ДЕМО-`. Это подпись существующих номеров, а не изменение ID или seed данных.
- Истёкшая сессия со старым initData предлагает закрыть Mini App и снова открыть его из бота. Подготовленный по нажатию текст из видимых полей доступен для копирования даже после блокировки формы. В persistent storage обращения не сохраняются; скрытые поля, пароли, cookies и Bridge в копию не включаются. Проверка подписи и пятиминутного срока в Java сохранена. Используется документированный [openMaxLink](https://dev.max.ru/docs/webapps/bridge), без выдуманного метода обновления initData.
- Сетевой deadline 20 секунд покрывает заголовки и тело ответа через AbortController; AbortSignal.any/timeout не нужны. Неизвестный исход команды сохраняет key/body для повтора.
- 409 требует успешной загрузки актуальных данных и явного решения. Ошибка загрузки не стирает ввод; 403/404 закрывают недоступную форму. Определённый отказ больше не блокирует кнопку навсегда. Дом сохраняется в памяти текущего пользователя только при действующем Membership.
- Бот Семёна на /start предупреждает про 112 и возвращает кнопку «Открыть приложение»; ошибки содержат requestId; отказ приглашения согласован как INVITATION_REJECTED.

## Граница и следующий шаг

Кнопка запуска MAX вызвана, но отдельное окно Mini App недоступно используемому инструменту управления Codex. Поэтому повторный живой вход и полный авторский сценарий этой версии в MAX не засчитаны; публичная страница и настоящий ответ бота подтверждены отдельно. Нативные iOS/Android, G2, независимая приёмка Софии и holdout остаются открытыми.

При финальной сверке обнаружено расхождение с передачей коллеги: в 2833443 нет seed apply/check и папки scripts/seed/. Чтение кода и `python3 scripts/seed_stand.py --help` подтверждают только house/invite/dispatcher. Семён должен передать недостающую реализацию либо подготовить роли существующими командами, а София независимо проверить R24 после входа трёх MAX-аккаунтов. Seed в этой проверке не запускался; текущие записи сохранены. Затем команда проходит G2 на телефонах, фиксирует результат и замораживает кандидат. Перед подачей повторить smoke и очереди на этом SHA. Внешний HTTP 80 и автоматическое продление TLS остаются прежними эксплуатационными долгами из [release](../release.md).
