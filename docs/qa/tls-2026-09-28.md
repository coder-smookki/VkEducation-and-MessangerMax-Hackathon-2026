## Сопровождение и откат

Не требовать HTTP-01 или освобождения 80 для этого сертификата. Проверять `certbot.timer`, журнал `certbot.service`, срок действующего сертификата и права файла credential. При смене ключа выдать только доступ к DNS этой зоны, затем повторить адресный dry-run.

Для отката локального маршрута удалить только добавленную строку hostname после сравнения с резервной копией; не перезаписывать чужие последующие изменения `/etc/hosts`. Возврат сохранённого `renewal.before.conf` возвращает ручное продление и снова создаёт эксплуатационный долг; не делать его без причины. Изменения DNS рабочего домена и откат приложения здесь не требуются.
