# Проверка минималистичного интерфейса 27.09.2026

Задачи K-01/K-06, Кирилл. Основание - новое поручение пользователя переработать весь рабочий интерфейс для простого использования разными возрастными группами, в цветах MAX и с умеренным движением. Изменены React-компоненты/CSS и проверки, серверные контракты и данные сохранены.

## Что изменилось

Компактная навигация, текстовые подписи и крупные поля, общая иерархия экранов автора/диспетчера/ошибок, три этапа создания, раздельные факты работ/наблюдения, редкие административные действия по раскрытию. Тема, крупный текст и отключение движения собраны в native dialog. Выход находится на странице доступа. История запрашивается только при раскрытии, API-пагинация сохранена.

Источник цвета - [MAX UI](https://dev.max.ru/ui) и [appearance.scss](https://github.com/max-messenger/max-ui/blob/1df07bd7c740374cd40612c07654c3fade7c2e9f/src/styles/variables/appearance.scss), повторно проверены 27.09 через Context7/GitHub. Фон/поверхности и фирменные синие/фиолетовые оттенки взяты из публичной дизайн-системы; светлая основная кнопка #0066CC затемнена для контраста. Это не заявление о сертификации полного брендбука MAX.

Появление страницы/диалога: transform3/6px за180ms, без затухания текста. Цветовые состояния150ms, нажатие100ms, загрузка пульсирует не больше трёх секунд. CSS media prefers-reduced-motion и пользовательская настройка отключают движение. Новых зависимостей, шрифтов с CDN и растровых изображений в runtime нет.

## Воспроизведение снимков

Из `frontend/`:

```sh
KOREN_DESIGN_CAPTURE=1 npm test -- --grep 'redesigned screen families'
```

Снимки в `tmp/redesign/` показывают работающий React на явно синтетических HTTP fixtures: список, карточка, создание, наблюдение, доступ и настройки в двух темах; редактор/подтверждение и широкие очередь/отчёт. Это не макеты и не скриншоты реального пользовательского аккаунта. Интеграционный тест дополнительно сохраняет `tmp/kirill/partial-real-light.png` и `partial-real-dark.png` после настоящих команд Java/SQL. Каталог tmp не коммитится.

Старые118PNG в `design/` являются историческим прототипом22.09. Актуальный визуальный источник - `frontend/src/` и [design.md](../design.md); матрица экранов сохраняет связь с API.

## Пределы

Автотесты и визуальный просмотр не доказывают удобство всех людей. Нужна независимая проверка Софии, несколько пользователей разных возрастов, screen reader и физические MAX iOS/Android. Предыдущий сброс preferences между новыми запусками в контейнере браузера Codex не считается исправленным по локальному reload. Полный G2 двумя реальными аккаунтами, M06/контакты, качество ML, нагрузка и прежние задачи HTTP80/TLS-продления этим редизайном не закрываются.
