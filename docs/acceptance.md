# Приёмка рабочего продукта

Это спецификация проверок, **ни один пункт не считается PASS по наличию документа**. ID `QA-E/A/R` не совпадают с ID изображений A01/R01. София указывает SHA, среду, предпосылки, факт и доказательство в [протоколе](testing.md).

Все основные QA-E, QA-A01..A11, QA-R обязательны. QA-A12 включается при публикации поиска; иначе NOT_APPLICABLE с выключенным UI, не PASS. Нет открытых P0/P1.

## Основной путь

### QA-E01 - Создание и уточнение

**Дано:** Действующий автор дома, Python доступен или выключен.

**Действие:** Ввести свет и дверь; ответить на вопрос о недостающем месте.

**Ожидается:** Уточнение только этому автору, сохранён исходный текст; две проблемы не сливаются.

**Владелец исправления:** S-02/K-02. Проверяет София.

### QA-E02 - Авторский review

**Дано:** DRAFT с двумя пунктами.

**Действие:** Исправить дверь, сохранить, подтвердить весь список, перечитать.

**Ожидается:** CONFIRMED только после команды автора, версии изменились по правилам, ремонт не подтверждён.

**Владелец исправления:** S-02/K-02. Проверяет София.

### QA-E03 - Приём и шаг

**Дано:** CONFIRMED виден диспетчеру.

**Действие:** Принять и задать двери действие/owner/обновление.

**Ожидается:** Отдельное acceptedAt/By; автор видит реальные данные после reload; deadline подписан обновлением.

**Владелец исправления:** S-03/K-03. Проверяет София.

### QA-E04 - Только сохранение отчёта

**Дано:** Два пункта, известные rounds.

**Действие:** Сохранить «Лампу заменили» без links.

**Ожидается:** Текст сохранён; наблюдения/round/status не меняются; ничего не отмечено в UI автоматически.

**Владелец исправления:** S-04/K-03. Проверяет София.

### QA-E05 - Точная связь

**Дано:** Сохранён отчёт о свете.

**Действие:** Выбрать свет и явно подтвердить связь.

**Ожидается:** Только свет получает новый round; дверь неизменна, авторское наблюдение ещё отсутствует.

**Владелец исправления:** S-04/K-03. Проверяет София.

### QA-E06 - Три наблюдения

**Дано:** Автор и новый REPORTED_DONE раунд.

**Действие:** На независимых fixtures выбрать RESTORED/PERSISTS/CANNOT_CHECK.

**Ожидается:** Только RESTORED повышает confirmed; остальные не успех, один ответ не переносится на дверь.

**Владелец исправления:** S-05/K-04. Проверяет София.

### QA-E07 - Частичный результат

**Дано:** Свет RESTORED, дверь NOT_RECEIVED.

**Действие:** Открыть карточку/бот/историю.

**Ожидается:** 1 из 2, дверь с отдельным следующим шагом, одинаковый caseId и версии.

**Владелец исправления:** S-05/K-04. Проверяет София.

### QA-E08 - Поздний полный результат

**Дано:** Новая отдельная работа по двери.

**Действие:** Связать новый отчёт, автор подтверждает дверь.

**Ожидается:** 2 из 2 только после второго наблюдения; вся цепочка доступна в истории.

**Владелец исправления:** S-05/K-04. Проверяет София.

### QA-E09 - Новый раунд

**Дано:** Свет уже RESTORED в старом раунде.

**Действие:** Подтвердить связь нового отчёта со светом.

**Ожидается:** Старый ответ в истории, текущий NOT_RECEIVED; старая кнопка не отвечает за новый раунд.

**Владелец исправления:** S-04/S-05. Проверяет София.

### QA-E10 - Ручной путь

**Дано:** Python недоступен или STUB.

**Действие:** Создать пункты/сохранить отчёт/выбрать связи вручную.

**Ожидается:** Основной процесс завершается, отказ явно обозначен, цитаты/анализ не выдуманы.

**Владелец исправления:** S-06/K-02/K-03. Проверяет София.

### QA-E11 - Отзыв и архив

**Дано:** Свет RESTORED, дверь ещё нет; независимые ветки.

**Действие:** Автор отзывает дверь с причиной; отдельно диспетчер архивирует дверь.

**Ожидается:** total=2; отзыв не allConfirmed, архив не успех; история/причина сохранены, свет неизменен.

**Владелец исправления:** S-05/K-04. Проверяет София.

### QA-E12 - Темы и доступность

**Дано:** Длинный ввод, desktop/mobile, обе темы.

**Действие:** System/light/dark, large1.25, отдельно 200%, Tab/диктор/клавиатура.

**Ожидается:** Не потерян ввод/фокус/CTA, нет горизонтальной потери контента, статус читается без цвета.

**Владелец исправления:** K-06. Проверяет София.


## Права, версии и некорректный ввод

### QA-A01 - Подпись и сессия

**Дано:** Невалидный/просроченный/повторно разобранный initData.

**Действие:** Вход, подмена userId/role, команды без CSRF, logout.

**Ожидается:** Нет входа/команды по недоверенным данным; лог не содержит секрет.

**Владелец исправления:** S-02. Проверяет София.

### QA-A02 - Чужой дом/ID

**Дано:** Два автора в разных домах и диспетчер одного.

**Действие:** Подставить case/item/reportId и cursor чужого дома.

**Ожидается:** Нет чтения/записи/истории/кандидатов другого scope, безопасный ответ без PII.

**Владелец исправления:** S-02/S-04. Проверяет София.

### QA-A03 - Отзыв права и replay

**Дано:** Команда ранее успешно исполнена.

**Действие:** Отозвать Membership, повторить чтение/тот же key.

**Ожидается:** Повтор не раскрывает сохранённый результат бывшему участнику.

**Владелец исправления:** S-02. Проверяет София.

### QA-A04 - Приглашение

**Дано:** Валидный, истёкший, использованный и неверный коды.

**Действие:** Два concurrent claim разными авторами; попытка выбрать DISPATCHER.

**Ожидается:** Только одно разрешённое потребление, роль не выбирается клиентом, rate limit действует.

**Владелец исправления:** S-02. Проверяет София.

### QA-A05 - Конкурентные версии

**Дано:** Две вкладки читают case/item одного поколения.

**Действие:** Обе отправляют разные команды с одной expected version.

**Ожидается:** Одна проходит, другая 409, нет потерянного обновления/частичных links.

**Владелец исправления:** S-03/S-04. Проверяет София.

### QA-A06 - Идемпотентность

**Дано:** Запрос с уникальным actor/operation/key.

**Действие:** Повторить то же тело; затем изменить target/тело/версии с тем же key.

**Ожидается:** Один эффект для идентичного тела; изменённое тело 409.

**Владелец исправления:** S-02..S-05. Проверяет София.

### QA-A07 - Устаревший контекст

**Дано:** Есть новый contentVersion/round/caseVersion.

**Действие:** Отправить старый callback, наблюдение или link.

**Ожидается:** Актуальные значения не меняются, UI предлагает перечитать и сохраняет ввод.

**Владелец исправления:** S-04/S-05. Проверяет София.

### QA-A08 - Смешанные субъекты

**Дано:** Два пункта: свет и дверь.

**Действие:** «Лампу заменили, дверь заменим завтра»; обратный порядок; дверь всё ещё сломана.

**Ожидается:** Состояние/цитата не переносится между пунктами; неоднозначность даёт воздержание.

**Владелец исправления:** S-06. Проверяет София.

### QA-A09 - Ложное evidence и stale ML

**Дано:** Ответ Python с чужим ID/неполным списком/выдуманной цитатой.

**Действие:** Вернуть его после новой редакции; включить emoji перед цитатой.

**Ожидается:** Ответ отвергнут/STALE, Unicode offsets проверены, нет автоматической команды.

**Владелец исправления:** S-06. Проверяет София.

### QA-A10 - Лимиты и структура

**Дано:** 0/20/21 items, поля до/сверх лимита, malformed JSON.

**Действие:** Отправить пустые/дубли/чужие IDs, bool вместо version, большое chunked тело, HTML/script и инструкцию выполнить команду внутри текста.

**Ожидается:** 422/400/413 до бизнес-эффекта; нет усечения, утечки текста, падения. HTML и инструкции остаются обычным текстом, не исполняются.

**Владелец исправления:** S-02/S-06. Проверяет София.

### QA-A11 - Авторство наблюдения

**Дано:** DISPATCHER видит чужое обращение.

**Действие:** Попытаться наблюдать/подтвердить список за автора.

**Ожидается:** 403/404 без изменения; широкая роль не подменяет автора.

**Владелец исправления:** S-02/S-05. Проверяет София.

### QA-A12 - Кандидаты

**Дано:** Кандидат разрешён на входе; права/версия меняются во время Python.

**Действие:** Вернуть пару двери/света, слабую близость, недоступный индекс.

**Ожидается:** Перепроверка scope/snapshot; точные item pairs; NOT_EVALUATED не «дубликатов нет».

**Владелец исправления:** S-06 (Should). Проверяет София.


## Сбои и выпуск

### QA-R01 - Python выключен

**Дано:** Основные сервисы готовы.

**Действие:** Остановить Python и пройти ручной путь.

**Ожидается:** Java сохраняет состояние, UI честно показывает manual, нет бесконечного spinner.

**Владелец исправления:** S-06/K-06. Проверяет София.

### QA-R02 - Неизвестный исход записи

**Дано:** Запрос дошёл до сервера, ответ потерян.

**Действие:** Повторить исходный key/тело, затем перечитать карточку.

**Ожидается:** Нет ложного success/ошибки потери, ровно один эффект. Отдельно отключить PostgreSQL до commit: сохранение не объявляется успешным, после восстановления безопасный повтор.

**Владелец исправления:** S-02..S-05/K-06. Проверяет София.

### QA-R03 - Inbox и crash

**Дано:** Событие сохранено durable.

**Действие:** Остановить worker после commit/ACK до обработки; перезапустить.

**Ожидается:** Событие подхвачено, бизнес-команда не удвоена.

**Владелец исправления:** S-05/S-07. Проверяет София.

### QA-R04 - Outbox и lease

**Дано:** Есть committed доставка, worker захватил lease.

**Действие:** Падение worker и истечение lease.

**Ожидается:** Запись возвращается в обработку, нет вечного RUNNING, актуальность проверяется.

**Владелец исправления:** S-07. Проверяет София.

### QA-R05 - Ошибки MAX

**Дано:** Управляемый MAX mock, отдельно настоящий smoke.

**Действие:** 429/Retry-After, 5xx, timeout, исчерпание попыток.

**Ожидается:** Ограниченный retry, понятный failed state; нет бесконечного опроса автора.

**Владелец исправления:** S-07. Проверяет София.

### QA-R06 - Рестарт и данные

**Дано:** Созданы пункты, links, observation/audit.

**Действие:** Перезапустить Java/Compose без удаления volumes.

**Ожидается:** Состояние/версии сохранены, при утрате сессии безопасный новый вход.

**Владелец исправления:** S-07. Проверяет София.

### QA-R07 - Устройства и сеть

**Дано:** MAX mobile iOS/Android/web в доступных версиях.

**Действие:** Клавиатура, safe-area, back, фон/возврат, 200%, offline.

**Ожидается:** Доступные действия и ввод не перекрыты; неподдержанная функция объяснена.

**Владелец исправления:** K-05/K-06. Проверяет София.

### QA-R08 - Source-build

**Дано:** Чистый SHA и изолированная проверочная среда.

**Действие:** Полная сборка/старт по инструкции с установкой зависимостей.

**Ожидается:** Измерено полное время/ресурсы; цель ≤5 мин проверяется фактом, не cached build.

**Владелец исправления:** S-07/K-07. Проверяет София.

### QA-R09 - Публичная поверхность

**Дано:** Release-конфигурация.

**Действие:** Проверить HTTPS, JS/логи, demo endpoints, Python/БД порты, API 404.

**Ожидается:** Нет секретов/публичной БД/demo; API-ошибка не HTML страницы SPA.

**Владелец исправления:** S-07/K-07. Проверяет София.

### QA-R10 - Миграция и restore

**Дано:** Тестовая БД на V2 и отдельная чистая БД.

**Действие:** Применить новые миграции; восстановить разрешённый backup.

**Ожидается:** Содержимое, связи и audit сохранены; есть измеренная процедура отката.

**Владелец исправления:** S-07. Проверяет София.
