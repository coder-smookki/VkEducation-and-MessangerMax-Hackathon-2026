## Как разрешать расхождения

Актуальное поручение пользователя выше старого документа. Доказательство готовности - код и проверка конкретной версии. Семантика - `domain.md`; HTTP - `api.md` с явной пометкой существующего/проектного; Python - экспорт из его типов; вид - `design.md` и матрица `screens.md`. При расхождении нельзя молча выбрать удобный вариант: исправить документы и затронутые типы в одной задаче.

`design/` содержит проектные состояния на синтетических данных. Надпись DONE в его реестре означает наличие изображения. `output/` не является источником секретов для агента и не коммитится автоматически. Старые персональные планы удаляются, история остаётся в Git.
