# Контекст для Claude

Прочитай [AGENTS.md](AGENTS.md) и следуй ему: это единые правила проекта для Claude и Codex. Затем [docs/README.md](docs/README.md), [текущее состояние](docs/memory/PROJECT_STATE.md), [инструкция выполнения задач](docs/ai-workflow.md), задача и персональный план её владельца.

Не восстанавливай требования по одному screenshot. Нужны предметная модель, права, версии, API, состояния ошибок и матрица экранов. Сначала проверь код: рабочий прототип дизайна не является работающим backend. Не создавай отдельную память в этом файле.

Связь экранов с Java описана в [frontend-handoff](docs/frontend-handoff.md), доказательства последней QA - в [протоколе](docs/qa/profile-visual-2026-09-27.md). Версия `dev` и опубликованный SHA различаются до отдельного deployment; проверяй [журнал](docs/operations-log.md). Исторические макеты и прежние протоколы не отменяют текущее состояние. Существующие записи стенда сохраняются; автотесты используют отдельную БД.
